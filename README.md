# Sensor-LDR-Ultrassonico
Luz automática com Arduino Uno: o HC-SR04 detecta presença e o LDR mede a luminosidade, acendendo o LED só com alguém por perto e o ambiente escuro. Mesmo código testado no Tinkercad e no hardware real. Desenvolvido como parte de um portfólio prático de sistemas embarcados.
